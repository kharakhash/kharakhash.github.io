# 4321 Puzzle

Репозиторий разделён на две версии:

## 1. `release/` — Укороченная версия для GitHub Pages
- **Назначение**: Публичная версия для игроков на [GitHub Pages](https://kharakhash.github.io/).
- **Особенности**:
  - Классический геймплей на квадратных полях (2х2, 3х3, ..., 10х10).
  - Режимы игры: Бесконечный, Quest, Akure.
  - Исправлено дублирование записей в статистике.
  - Поддержка темной и светлой тем, плавная анимация, переключатели значений.
  - Без гексагональных полей, без экранного hex-пада и без специфичных hex-стилей.

## 2. `project/` — Полная версия с рефакторингом
- **Назначение**: Полный проект со всеми экспериментальными модулями и инструментами разработки.
- **Особенности**:
  - Полный модульный рефакторинг архитектуры (`EventBus`, `StateManager`, `StorageService`, `AnimationService`, `ModeRules`, `GameCore`, `WorkerService`).
  - Поддержка гексагональных полей (3х3х3, 5х5х5) с расчётом кубических координат и сотовой сетки.
  - Экранный контроллер `hexControlsPad` и управление 6 направлениями (клавиатура, свайпы).
  - Конструктор уровней (Level Editor) с DSL-парсером/сериализатором.
  - Полный набор автоматических тестов (20 тестов).
  - SAT-утилиты и солверы.

## Запуск и тестирование
- **Запуск тестов обоих проектов**:
  ```bash
  npm test
  ```
- **Запуск тестов только project**:
  ```bash
  npm run test:project
  ```
- **Запуск тестов только release**:
  ```bash
  npm run test:release
  ```
- **Локальный запуск**:
  ```bash
  python3 -m http.server 8000
  ```
  - `http://localhost:8000/` — корневой шлюз автоматически перенаправляет на `./release/`
  - `http://localhost:8000/release/` — запуск версии release
  - `http://localhost:8000/project/` — запуск версии project
